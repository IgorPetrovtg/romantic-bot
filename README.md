# ❤️ Romantic Telegram Bot

Telegram-бот на Python, который ежедневно отправляет тёплые пожелания и комплименты близкому человеку.

## ✨ Возможности
* **Утренняя рассылка (09:00 UTC+5):** случайное доброе пожелание на день.
* **Вечерняя рассылка (22:00 UTC+5):** тёплое пожелание спокойной ночи.
* **Интерактивные ответы:** реагирует на сообщения со словами *«привет»*, *«люблю»* и поддерживает диалог.
* **Управление подпиской:** команды `/start` (подписаться) и `/stop` (остановить рассылку).
* **Безопасность:** токен бота хранится в `.env`, а список подписчиков (`users.json`) исключён из репозитория.

## 🚀 Установка и запуск

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com
   cd romantic-bot
   ```

2. **Создайте виртуальное окружение и установите зависимости:**
   ```bash
   python -m venv .venv
   # Для Windows:
   .venv\Scripts\activate
   # Для Linux/macOS:
   source .venv/bin/activate

   python -m pip install -r requirements.txt
   ```

3. **Настройте токен:**
   Создайте в корне проекта файл `.env` и добавьте в него токен от [@BotFather](https://t.me):
   ```env
   BOT_TOKEN=ваш_токен_бота
   ```

4. **Запустите бота:**
   ```bash
   python main.py
   ```
